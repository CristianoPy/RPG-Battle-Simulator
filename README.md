# RPG Battle Simulator

A beginner-friendly console-based RPG Battle Simulator developed in C#.

## About the Project

This project was created to practice fundamental C# programming concepts through a simple turn-based RPG combat system.

The player fights against an enemy using attacks, critical hits, healing potions, or the option to escape from battle.

## Features

- Turn-based combat system.
- Random damage calculation.
- Critical hits with a 10% chance and 3x damage.
- Player and enemy health systems.
- Healing potions that restore up to 20 HP.
- Limited potion inventory.
- Victory, defeat, and escape outcomes.
- Interactive console menu.

## Technologies

- C#
- .NET
- Visual Studio

## How to Play

Choose an action from the battle menu:

1. **Attack** – Attack the enemy.
2. **Use Potion** – Restore up to 20 HP.
3. **Run** – Escape from the battle.

Defeat the enemy to achieve victory!
